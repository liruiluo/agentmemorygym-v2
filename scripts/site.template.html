The research question

A strong teacher is only
half the story.

Adding a memory system does not ensure that it can be taught. On-policy distillation needs both sides to meet at the same interface.

Student side

Will it use memory
in the first place?

The student has to sample meaningful writes and reads. An action that never appears gets no on-policy supervision.

write→read→continue
Teacher side

Can it judge
what was written?

A strong task model can still be unfamiliar with a memory protocol. Its targets need to guide the content the student actually produces.

same context+student’s write

Start with a language they share: files.

Ordinary Bash lets the agent create, revise, search and read its own memory. The familiar operations make the channel usable; training teaches what to keep and when to use it.

CAMP-II · the method

The student acts.
The teacher scores.

One task-acting policy learns both task actions and memory operations. The frozen teacher supplies token-level feedback on the student’s own response.

A familiar interface.
A larger learning gain.

CAMG-II · the environment suite

Five task worlds.
One file-memory interface.

Each environment keeps its native task. All give the policy ordinary Bash access and an episode-persistent workspace. One policy is trained jointly across the five.
