The research question

A strong teacher is only
half the story.

Adding a memory system does not ensure that it can be taught. On-policy distillation needs both sides to meet at the same interface.

Student side

Will it use memory
in the first place?

The student has to sample meaningful writes and reads. An action that never appears gets no on-policy supervision.

write→read→continue
Teacher side

Can it judge
what was written?

A strong task model can still be unfamiliar with a memory protocol. Its targets need to guide the content the student actually produces.

same context+student’s write

Start with a language they share: files.

Ordinary Bash lets the agent create, revise, search and read its own memory. The familiar operations make the channel usable; training teaches what to keep and when to use it.

CAMP-II · the method

The student acts.
The teacher scores.

One task-acting policy learns both task actions and memory operations. The frozen teacher supplies token-level feedback on the student’s own response.

At inference time the trained student acts without the distillation teacher.

Understanding the result

More actions to teach.
A clearer teaching signal.

The paper checks both sides of the interface, then tests whether the improvement depends on supervising memory content.

Mask the memory-content loss.
Most of the gain disappears.

Mask the same number of tokens at random and the score stays near CAMP-II. The result depends on which tokens receive supervision, not just how many.

CAMG-II · the environment suite

Five task worlds.
One file-memory interface.

Each environment keeps its native task. All give the policy ordinary Bash access and an episode-persistent workspace. One policy is trained jointly across the five.

Shop

WebShop

Complete a chain of six purchases.

Carry product evidence and earlier constraints into later sessions.

Coding

SWE-smith

Repair a real repository.

Retain the diagnosis, code locations and test outcomes across contexts.

AutoResearch

OpenMLE

Run and improve an ML experiment.

Keep experiment choices, measurements and the next hypothesis.

General

MiMo

Finish a multi-tool knowledge-work task.

Preserve requirements, intermediate outputs and unfinished steps.

Visual

MiMo / Web development

Build and refine a website.

Save visual findings and an implementation plan, then resume.

“Coding agent” describes how memory is operated. The tasks themselves extend beyond coding.
