01 / The idea

What an interface
has to be.

Distillation decides what a student can learn by what the student will emit and what the teacher can score. An interface has to satisfy both.

CAMP-II teaches through ordinary file operations, which the code-pretrained student already performs and the frozen teacher already judges. Nothing has to be taught about the interface itself.

The student has to emit it.

Supervision only reaches what the policy samples. On the file interface the student already writes notes and reads them back, so memory actions appear in the rollout instead of staying at zero.

03 / The method

Teaching through
the interface.

The student samples an action, the teacher scores every token of it, and the learner averages that signal over an asynchronous stream of episodes.

A
act

Act on the task

Native tool calls and ordinary shell commands share one response space, so a file write is an action like any other.

B
score

Score every token

The frozen teacher reads the same visible context and returns a per-token distribution over what the student just wrote.

C
learn

Close the gap

The learner follows the reverse-KL direction on memory content while rollouts keep arriving from the published weights.
